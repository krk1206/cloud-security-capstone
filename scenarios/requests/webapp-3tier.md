안녕하세요. 3계층 웹 서비스 운영팀입니다.

보안 점검에서 "관리용 서버(Bastion)의 SSH(22번 포트)가 인터넷 전체에 열려 있다" 는 지적을 받았습니다. 그리고 웹 서버가 데이터베이스에 바로 붙어 있는 것 같다는 의견도 있었습니다.
아래 조건대로 고쳐 주시고, 고친 것이 실제로도 그렇게 동작하는지 시험 환경에서 확인한 뒤 PR 로 알려 주세요.

## 요청 조건 (꼭 지켜 주세요)

1. Bastion 서버 SSH(22)는 관리자 접속 대역(203.0.113.0/24 · 198.51.100.0/24)에서만 접속되게 해 주세요.
2. 사용자는 지금처럼 인터넷에서 HTTPS(443)로 접속할 수 있어야 하고, 웹 서버까지 요청이 전달돼야 합니다.
3. 데이터베이스(3306)는 API 서버에서만 접속돼야 합니다. 웹 서버가 데이터베이스에 바로 붙으면 안 됩니다.
4. 지적된 곳 말고는 바꾸지 말아 주세요. 설계에 없는 통신을 새로 열거나, 설계에 있는 통신을 막거나, 새 보안 문제를 만들면 안 됩니다.
5. 운영에 반영하기 전에 시험 환경(샌드박스)에서 실제로 확인하고, 저희 담당자가 승인한 뒤에 반영해 주세요.

## 참고
