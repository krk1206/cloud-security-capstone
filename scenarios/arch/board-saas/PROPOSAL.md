## 1. 서비스 구성

- 사용자는 인터넷에서 웹 서버에 접속합니다 (HTTP 80, HTTPS 443).
- 웹 서버는 데이터베이스(MySQL)에 글을 저장합니다.
- 관리자는 점프 서버(Bastion)를 거쳐서만 웹 서버에 SSH 로 들어갑니다.

## 2. 보안 조건 (꼭 지킬 것)

1. 인터넷에 공개하는 것은 웹 서버의 80 · 443 뿐입니다. 그 밖의 포트는 공개하지 않습니다.
2. 점프 서버 SSH(22)는 **본사 사무실(203.0.113.0/24)** 에서만 허용합니다. 다른 곳에서는 접속할 수 없어야 합니다.
3. 웹 서버 SSH(22)는 점프 서버에서만 허용합니다.
4. 데이터베이스(3306)는 웹 서버에서만 접속할 수 있어야 합니다. 인터넷 · 점프 서버에서는 접속할 수 없어야 합니다.
5. 설정 변경은 사람이 검토 · 승인한 뒤에만 반영합니다.
