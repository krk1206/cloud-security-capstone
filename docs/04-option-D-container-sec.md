# [D안] 쿠버네티스/도커 기반 AI 모델 자동 배포 및 컨테이너 보안 경량화 플랫폼

## 1. 프로젝트 개요
- **핵심 컨셉:** 오픈소스 AI 서비스 배포 시 불필요한 권한과 용량을 줄인 보안 경량화 컨테이너로 자동 빌드 및 배포하는 인프라 플랫폼.
- **주요 기능:**
  - 오픈소스 AI 모델 원클릭 컨테이너 배포
  - 컨테이너 공격 표면 축소 (최소화 이미지 빌드 및 권한 제한)
  - 인프라 자원 사용량 및 컨테이너 간 통신 보안 모니터링
- **기술 스택:** Linux, Docker, Kubernetes, Shell Script, Python
