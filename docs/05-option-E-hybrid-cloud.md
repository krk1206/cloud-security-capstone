# [E안] 하이브리드 클라우드(온프레미스 ↔ AWS) 연동 및 통합 보안 모니터링 구축

## 1. 배경 및 필요성
- 많은 기업들이 보안상 중요한 데이터는 온프레미스(자체 서버)에 두고, 확장성이 필요한 서비스는 퍼블릭 클라우드(AWS)에 두는 **하이브리드 클라우드** 구조를 채택함.
- 이종 인프라 간 안전한 암호화 통신 채널 형성 및 파편화된 보안 로그의 중앙 통합 모니터링 체계 필요.

## 2. 시스템 아키텍처 및 핵심 기능
1. **하이브리드 터널링 네트워크 구축:**
   - 자체 서버(Linux/Docker)와 AWS VPC 간을 **OpenVPN / AWS Site-to-Site VPN**을 통해 암호화 터널로 연결.
2. **중앙 로그 수집 및 일기화:**
   - 온프레미스 및 AWS 자원에서 발생하는 시스템/보안 로그를 **Elasticsearch / Fluentbit**을 통해 중앙 서버로 실시간 수집.
3. **통합 보안 모니터링 & 위협 알림:**
   - **Grafana** 대시보드를 구축하여 온프레미스-클라우드 간 트래픽 흐름, 비정상 접속 시도, 인프라 상태를 일원화하여 모니터링.

## 3. 기대 효과
- 온프레미스 리눅스 인프라와 AWS 클라우드를 아우르는 넓은 네트워크/보안 시야 확보.
- 엔터프라이즈 하이브리드 클라우드 환경 구축 실무 경험 어필.
