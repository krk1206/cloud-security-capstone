# [E안] 하이브리드 클라우드(온프레미스 ↔ AWS) 연동 및 통합 보안 모니터링 구축

## 1. 프로젝트 개요
- **핵심 컨셉:** 자체 서버(온프레미스/도커)와 퍼블릭 클라우드(AWS)를 VPN으로 안전하게 연결하고 보안 정책 및 로그를 중앙에서 통합 관리.
- **주요 기능:**
  - OpenVPN/AWS VPN Gateway 기반 하이브리드 네트워크 구축
  - 이종 인프라 간 보안 로그 실시간 수집 및 중앙화
  - 하이브리드 인프라 보안 정책 일괄 적용 및 모니터링
- **기술 스택:** Linux, AWS, Docker, OpenVPN, ElasticSearch, Grafana
