# [B안] 도커/쿠버네티스 CI/CD 환경에서의 AI 기반 보안 취약점 자동 진단 파이프라인

## 1. 배경 및 필요성
- 소프트웨어 배포 속도가 빨라짐에 따라 개발 단계부터 보안을 적용하는 **DevSecOps**가 필수적임.
- 컨테이너 빌드/배포 시 보안 검증을 자동화하여 취약한 애플리케이션이 운용 환경에 올려지는 것을 사전 차단해야 함.

## 2. 시스템 아키텍처 및 핵심 기능
1. **CI/CD 파이프라인 구축:**
   - **GitHub Actions**를 이용해 개발자의 코드 커밋/PR 시 자동으로 도커 이미지 빌드 수행.
2. **Shift-Left 보안 스캐닝:**
   - 파이프라인 내부에서 **Trivy / Grype**를 실행하여 컨테이너 이미지의 OS/라이브러리 취약점 자동 탐지.
3. **AI 코드 피드백 & 배포 게이트:**
   - 취약점 탐지 시 배포를 자동 중단(Fail)하고, **LLM API**가 취약점이 발생한 코드 라인과 수정 patch 가이드를 PR 댓글로 피드백.
   - 보안 기준을 통과한 안전한 컨테이너만 쿠버네티스/AWS 환경에 최종 배포.

## 3. 기대 효과
- 최신 IT 업계 필수 스택인 CI/CD 파이프라인과 DevSecOps 방법론 완전 습득.
- 단순 구축을 넘어 배포 품질 제어 및 보안 가시성 확보 경험 축적.
