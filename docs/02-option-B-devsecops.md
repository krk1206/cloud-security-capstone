# [B안] 도커/쿠버네티스 CI/CD 환경에서의 AI 기반 보안 취약점 자동 진단 파이프라인

## 1. 프로젝트 개요
- **핵심 컨셉:** 소스코드 빌드 및 배포(CI/CD) 과정에서 보안 취약점을 자동으로 스캐닝하고, AI가 문제 원인과 코드 수정 방안을 제시하는 자동화 파이프라인.
- **주요 기능:**
  - GitHub Actions 기반 CI/CD 파이프라인 연동
  - 컨테이너 이미지 정적/동적 보안 스캐닝
  - AI 기반 보안 취약점 코드 자동 조치 가이드 생성
  - 보안 통과된 컨테이너만 클라우드 자동 배포
- **기술 스택:** Docker, Kubernetes, GitHub Actions, Trivy, Python, LLM API
