## 설계에서 정한 것 (근거)

- **plan JSON 을 오라클 입력으로** 쓴다. Terraform 이 변수·locals·dynamic 을 이미 풀어주므로 02/03/04 가 자연히 처리된다. HCL 파서 의존성도 필요 없다.
- **미확정 값은 참조로 모호하지 않을 때만 채운다.** 06 의 `prefix_list_ids = [aws_ec2_managed_prefix_list.world.id]` 는 plan 에서 unknown 이지만 `configuration.expressions.ingress.references` 로 하나뿐인 참조를 찾아 전개한다. 규칙 여러 개에 슬롯이 나뉘면 UNKNOWN.
- **inline ingress 미선언 = provider computed(unknown)** 이라는 provider 동작을 확인했다(05, 15). 설정에 선언이 없고 HCL 에 dynamic 블록도 없으면 "선언된 inline 규칙 없음" 으로 보고 caveat 를 남긴다. HCL 을 못 보면 UNKNOWN.
- **참조와 리터럴이 섞인 SG 목록은 plan 에 리터럴이 안 나온다**(13). HCL 에서 원소를 세어 외부 sg-… 를 잡고 UNKNOWN 을 낸다.
- **00-baseline 은 정상 패치가 아니다.** 브리핑의 "00-baseline 정상 패치는 통과" 는 오해였고, 정상 수정본 00b 를 따로 만들었다.
- **V2 는 개수가 아니라 키 집합** (룰|파일|리소스). 새 CRITICAL/HIGH 만 차단, 나머지 WARN. 기존 finding(0104 egress) 은 차단하지 않는다 → worklog 2026-09-11 의 "0104 때문에 항상 차단" 문제 해소.
- **위험도와 검증은 별개 축.** cidr_split 은 위험도 LOW 인데 V6 FAIL 로 BLOCK. LLM 등급 제안은 하향만.
