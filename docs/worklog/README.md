# 작업 기록 (Worklog)

날짜별 작업 내용과 그 근거를 남긴다. 무엇을 했는지뿐 아니라 **왜 그렇게 했는지**,
**어디서 막혔고 어떻게 풀었는지**를 함께 기록한다.

## 왜 남기는가

1. **재현성** — 몇 주 뒤에 같은 작업을 다시 할 때 명령어와 이유를 찾을 수 있다
2. **발표 준비** — "어떻게 이 결론에 도달했는가"를 설명할 근거가 된다
3. **팀 공유** — B, C가 A가 만든 것을 이해할 수 있다
4. **실수 방지** — 한 번 막힌 지점을 다시 밟지 않는다

## 작성 형식

각 문서는 다음을 포함한다.

- **요약** — 한눈에 보는 결과
- **타임라인** — 시간순 흐름
- **상세** — 실제 명령어와 그 의미
- **막혔던 지점** — 원인과 해결. 가장 중요한 부분
- **확인된 사실** — 추측이 아니라 측정으로 확인한 것
- **개념 정리** — 그날 새로 이해한 것
- **다음에 할 것**
