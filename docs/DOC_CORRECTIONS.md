## 4. 기능 구현과 주장의 경계

- 이 저장소의 테스트가 보여주는 것: **정의된 케이스에서** 검증 계층이 설계대로 판정한다는 것.
- 보여주지 **않는** 것: 기업 실용성, 실제 LLM 출력에서의 기만적 패치 발생률, 실제 AWS 배포 후 상태(V7 미실행), 실제 통신 차단(V8 미실행), 사람 승인 포함 MTTR.
- mock 성공은 API 연동 성공이 아니고, Trivy 재스캔 통과는 보안 검증 성공이 아니다 (V1 과 V6 의 차이가 이 프로젝트의 요지다).
