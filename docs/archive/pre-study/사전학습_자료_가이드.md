## 9/2 (화) — 공통: DevSecOps·Git 기초

**CI/CD 개념 (30분~1시간)**
- Atlassian, "What is CI/CD?" — https://www.atlassian.com/continuous-delivery/continuous-integration
  - 빌드-테스트-배포 파이프라인의 기본 구조를 그림으로 설명. Shift-Left 개념도 함께 다룸
- GitHub Docs, "About continuous integration" — https://docs.github.com/actions/about-github-actions/about-continuous-integration
  - GitHub Actions 관점에서 CI가 왜 필요한지 짧게 정리

**Git 기초 (1~2시간, 실습 위주)**
- Learn Git Branching — https://learngitbranching.js.org/?locale=ko
  - 브라우저에서 바로 실습하는 인터랙티브 Git 학습. 한국어 지원. "커밋/브랜치" 기본 챕터만 해도 충분
- GitHub Docs Quickstart — https://docs.github.com/get-started/quickstart
  - 저장소 생성, 커밋, PR까지 한 번 손으로 따라 해보기

**할 일:** 실제로 GitHub에 테스트 저장소 하나 만들어서 커밋 1개, 브랜치 1개, PR 1개를 직접 만들어본다.
