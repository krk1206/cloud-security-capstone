# 업무 시나리오 — 처음부터 끝까지, 기록이 어떻게 끝나나 (2026-11-02, D-42)

검토 문서(11-02): "업무 시나리오를 처음부터 끝까지 돌리고, 모든 시나리오는 **무엇을 확인했고 · 누가 어떤 결정을 했으며 · 무엇이 남았는지** 로 끝나야 한다."
프로그램은 ⑧ 맨 아래 **'이 기록의 끝맺음'** 칸(확인한 것 · 결정 · 남은 것 — `web/product._closing`)과 PR 본문 맨 위의 같은 세 줄(`server.closing_markdown`)로 모든 기록을 그렇게 끝낸다. 새로 판정하지 않고 결론 · 결정 기록 · 미검증 목록을 문장으로 옮긴 것이다.

아래 9개는 프로그램이 지원하는 흐름을 시작 방식 × 결과 갈래로 나눈 것이다 (검토 문서의 세 시작 방식: 기존 요구사항 가져오기 · 현재 코드에서 초안 · 기본 보안 정책만; 세 실패 갈래: 수정안 부적합 · 실행 오류 · 검증 불가). 각 줄의 'E2E' 열은 그 흐름을 **실제로 돌린 자동 시험**의 검사 번호다 (클라우드 작업 환경, 실제 Trivy · tofu 오프라인 plan, AI 는 시험용 대역, AWS 없음). 시험 이름: `main` = e2e/main_e2e.js (87), `proj` = e2e/proj_e2e.js (52), `team` = e2e/team_e2e.js (40 — 팀 3계층 예제 ①~⑧, D-49 · 가상 고객 요청서 D-50), `scen` = e2e/scen_e2e.js (16), `tb` = e2e/tb_e2e.js (46 — ⑦ AWS 시험 환경 5단계, 9차 D-43), `walk` = e2e/walk_e2e.js (54 — 화면 넘침 · 겹침 · 이동), `rb` = e2e/rb_try.js (18 — ⑤ 설계도대로 자동 수정, D-45), `prop` = e2e/proposal_e2e.js (29 — 고객 제안서 예제 ①~⑧, D-46 · 미리 분석 D-47 · 번호마다 그림 바뀜 D-48), `req` = e2e/req_e2e.js (31 — 팀 3계층 요청 2 · 3, D-51). walk 는 고객 제안서 예제 화면 4개를 더해 66, 요청 2 · 3 화면 8개(② ~ ⑤)를 더해 78.

- 시험 환경 반영(apply) · V7 · V8 측정은 **사람이 ⑦ 의 확인 창에서** 한다 — `tb` E2E 는 가짜 terraform · 가짜 aws 로 그 확인 창까지 누르는 것이고(실제 AWS 없음), 실제 AWS 측정 결과를 가진 기록은 10-23 의 20261023-124957-af6f0b 뿐이다 (CLAUDE.md: 실제 apply 는 사람만). 가짜 aws 는 자격증명 오류를 내므로 E2E 안의 측정 결과는 '판정 불가(UNVERIFIED)' 로 남는다 — 결과 칸은 그것을 그대로 보인다.
- PR 만들기는 확인 창에서 **취소**한다 — 실제 push · PR 생성은 사람이 PC 에서. 예제 폴더를 고치는 PR 은 **시연용이라 병합하지 않는다** (D-44: 예제는 실험 재료 — GitHub 의 단위 시험 검사가 그 PR 에서 실패하는 것이 정상).
- AI 는 시험용 대역(미리 적어 둔 답)이다 — 실제 Claude 가 만든 수정안으로 같은 검사를 돌린 기록은 `experiments/candidate-sets/arch-3tier-sg/AI_CANDIDATES_2026-10-20.json`(AI 수정안 3개 · 작성 경위)과 `RESULTS_2026-10-23_pc.md`(ai-claude-r1~r3: V6 FAIL → 차단, PC 실측)에 있다. 프로그램 안 'AI 에게 고치게 하기'(llmfix) 를 실제 Claude Code 로 돌린 기록(`data/llm_runs/`)은 이 작업 환경에 없다 — PC 에서 돌렸다면 PC 의 data 폴더에만 있다 (전달 ZIP 에서 data 는 뺌). 실제 Claude Code 실행 증거가 필요하면 PC 에서 한 번 돌리고 그 run.json 을 `experiments/.../results-history/` 에 옮긴다 (사람).
- 검토 문서가 든 시나리오 목록 원문은 이 문서에 없다 — 위 9개는 프로그램 흐름 기준으로 나눈 것이라, 검토자의 목록과 이름이 다를 수 있다. 다르면 이 표의 번호만 바꾼다.
